# PyTorch-Deep-Learning-Basics
This repository contains my learning journey with **PyTorch**, covering everything from basic tensor operations to building and evaluating complex CNN architectures.

## 📁 Repository Structure

### 1. Fundamentals
* `torch_basic.ipynb`: Introduction to PyTorch tensors, autograd, and basic operations.
* `Custom_Dataset.ipynb`: Learning how to build custom Dataset and DataLoader for efficient training.

### 2. Classification Tasks
* `binary_classification.ipynb`: Implementing a model to solve two-class problems.
* `multiclass_classification.ipynb`: Comprehensive guide to multi-class classification.
* `muticlass_classification_short.ipynb`: A condensed version of the multi-class classification workflow.
* `multiclass_functions1.py` & `multiclass_functions2.py`: Modularized utility functions for training and evaluation.

### 3. Model Analysis & Testing
* `CNN_Feature_map.ipynb`: Visualizing Feature Maps to understand what CNNs actually "see" at each layer.
* `mininet_test.ipynb`: Experimenting with lightweight model architectures (MiniNet).

## 🛠 Tech Stack
- **Language:** Python
- **Framework:** PyTorch
- **Environment:** Google Colab / Jupyter Notebook
- **Libraries:** NumPy, Matplotlib, Torchvision

## 💡 What I Learned
- **Tensor Management:** Handling data dimensions and GPU/CPU device mapping.
- **Model Modularity:** Breaking down training loops into reusable `.py` scripts.
- **Explainable AI (XAI):** Gaining intuition on spatial hierarchy by visualizing feature maps.
- **Data Pipeline:** Handling raw data and transforming it into model-ready formats.
